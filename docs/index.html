🧠 AI Pipeline

How It Works

Four stages from webcam pixel to system action — all running locally on your machine.

01

Webcam Capture

OpenCV captures 30 FPS frames from your webcam in a dedicated background thread, preventing UI blocking.

02

MediaPipe Landmark Detection

The HandLandmarker model tracks all 21 3D keypoints on your hand — fingertips, knuckles, and wrist — in milliseconds.

03

Geometric Gesture Classification

A custom detect_gesture() function checks if each fingertip y coordinate is above its PIP joint to determine if a finger is extended or folded.

04

OS Action Execution

Matched gestures trigger pycaw for Windows audio control or pyautogui for keyboard simulation, with a 0.8s cooldown timer.

🚀 Quick Start

Run in 3 Steps

Requires Python 3.8+ and a webcam. Works on Windows (with full volume control via pycaw) and macOS/Linux (with keyboard fallback).

Step 1 — Clone the repo
git clone https://github.com/Gunashree2007/AIFE.git
cd AIFE
Step 2 — Install dependencies
# Install all required packages
pip install -r requirements.txt
Step 3 — Launch the app
python app.py

# Then open your browser to:
http://localhost:5000

💡 The MediaPipe hand landmark model (7.8 MB) is auto-downloaded on first launch — no manual setup needed.
